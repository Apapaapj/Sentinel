# VulnScanner — Production-Ready Website Vulnerability Scanner

## Features

✅ **10 Vulnerability Checks**
- XSS (Cross-Site Scripting)
- SQL Injection
- CSRF Protection
- Security Headers
- SSL/TLS Validation
- Exposed Files
- Cookie Security
- Subdomain Enumeration
- Response Analysis
- Outdated Frameworks

✅ **Production-Ready**
- Next.js 14 with App Router
- TypeScript
- Rate Limiting (100 req/hour)
- Security Headers
- Responsive UI
- Dark/Light/System themes

## Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## Deploy to Vercel

```bash
vercel
```
